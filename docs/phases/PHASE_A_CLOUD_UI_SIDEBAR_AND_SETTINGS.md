## 1. الأهداف والمتطلبات
1. **إزالة الشاشات الخاصة بالديسكتوب من واجهة النظام السحابي:**
   - إخفاء الشاشات غير الملائمة لبيئة السحابة من القائمة الجانبية ومن شاشة `/settings`:
     - `new-file` (إنشاء ملف جديد)
     - `backup` / `restore` (نسخ احتياطي واستعادة محلية)
     - `data-rotation` (تدوير البيانات)
     - `invoice-maintenance` (صيانة الفواتير)
     - `file-manager` (إدارة الملفات المحلية)
     - `android-devices` (أجهزة الأندرويد المحلية)
     - `data-sync` / `sync-*` (مزامنة البيانات المحلية)
     - `license` / `report-designer` / `online-support` / `check-updates`
   - الحفاظ على تعريفات `modules` و`allScreens` الأساسية في `apps/staff/lib/navigation.ts` لضمان توافق اختبارات `navigation.spec.ts` و`ai-help.spec.ts`، مع تطبيق التصفية والهيكلة السحابية في `AppShell` و`/settings`.
2. **تنظيم القائمة الجانبية وفق هيكل موحد (`التعاريف · العمليات · التقارير`):**
   - تصنيف عناصر كل قسم رئيسي إلى 3 مجموعات فرعية قياسية:
     - **التعاريف** (البطاقات الأساسية، الدليل، الأصناف، العملاء والموردين، الصناديق والبنوك...)
     - **العمليات** (السندات، الفواتير، القيود، المناقلات، الجرد...)
     - **التقارير** (الكشوفات، الأرصدة، التحليلات...)
3. **تبويبات رئيسية في أسفل القائمة الجانبية:**
   - **🛒 سوق الإضافات (`/settings/marketplace`)**: تبويب رئيسي مستقل يظهر مباشرة فوق «طلب المساعدة».
   - **🛟 طلب المساعدة (`/support/help`)**: تبويب رئيسي مستقل في أسفل القائمة للتواصل المباشر مع إدارة المنصة.
4. **قائمة الملف الشخصي للمستخدم في الشريط العلوي (`Topbar User Profile Menu`):**
   - إضافة زر وقائمة منسدلة / نافذة للملف الشخصي في أعلى الشاشة (`AppShell`) تتيح للمستخدم:
     - عرض وتعديل اسمه الكامل (`PATCH /me/profile` أو `/users/me`)
     - الانتقال السريع لتغيير كلمة المرور (`/settings/change-password`) والتحقق بخطوتين (`/settings/two-factor`)
     - عرض بيانات العضوية والمنشأة والفرع وتسجيل الخروج.
5. **التجاوب الكامل مع جميع أحجام الشاشات (Responsive Layout):**
   - ضمان عمل الجداول، النماذج، الشريط العلوي، والقائمة الجانبية بسلاسة على الجوال، التابلت، والشاشات العريضة.
